<h1>Notepad Swing GUI</h1>

<h2>Introduction</h2>
<p>This is a Notepad desktop application created using Java and the Swing framework. It provides a simple text editing environment with file management, text formatting, undo and redo functionality, and font customization. The project was developed to practice Java GUI development, event handling, file manipulation, and object-oriented programming. Please refer below for the technologies and features of this project. Thanks!</p>

<h2>Technologies Frameworks</h2>
<ul>
  <li><b>JDK 18+</b> - Java Version</li>
  <li><b>Java Swing</b> - GUI Framework</li>
  <li><b>AWT</b> - Layout Management, Component Orientation & Event Handling</li>
  <li><b>JTattoo</b> - Look and Feel Customization</li>
</ul>

<h2>Features</h2>
<ul>
  <li>📃 Write and edit text</li>
  <li>🔄 Clear the current notepad</li>
  <li>📂 Open a <code>.txt</code> file</li>
  <li>💾 Save a new <code>.txt</code> file</li>
  <li>💾 Save changes to the current file</li>
  <li>🟥 Close the notepad</li>
  <li>⬅ Undo text changes</li>
  <li>➡ Redo text changes</li>
  <li>🎁 Wrap or unwrap text</li>
  <li>👈 Left-align text</li>
  <li>👉 Right-align text</li>
  <li>🅱 Apply bold font style</li>
  <li>ℹ Apply italic font style</li>
  <li>🔤 Apply plain font style</li>
  <li>🅱️ Apply bold italic font style</li>
  <li>🔗 Change font family</li>
  <li>📏 Adjust font size</li>
   <li>🎨 Change font color</li>
  <li>📜 Scroll through the document</li>
</ul>
